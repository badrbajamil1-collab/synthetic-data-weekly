# One-Page Status Note — Weekly Synthetic Data Research Agent

*Date: 2026-11-21 · Branch: `main` · Evidence: [`progress/`](../progress/README.md)*

## What works

- **Phase 0–1 (Topic, sources & collectors):** 18 sources across 6 collectors (3 arXiv queries, 2 Google News RSS queries, 13 research/vendor blog feeds, 1 combined Reddit feed, 4 Hacker News tags, 6 GitHub queries + bounded releases) and 22 Well7-tuned keywords in [`config.yaml`](../config.yaml) (reasons documented in [`docs/sources.md`](sources.md)). Phase 0 manual baseline (`23–29 Oct 2026` in `progress/phase-0-manual/`) established the gold-standard format (6 picks, 1 tool, 2 worth-a-look). All collectors emit one `Item` shape over a fixed Saturday–Friday reporting week (`src/synthetic_data/week.py`).
- **Phase 2 (Normalise, dedupe, memory & ranking):** URL normalisation (`links.normalize_url`) strips tracking parameters and folds arXiv `vN` versions; primary-source dedupe + title similarity (`0.80`) collapse duplicate coverage; atomic SQLite `history.db` (+ `.bak` recovery) prevents links from repeating across weeks. LLM scoring (`rank.py` + `llm.py`) rates both `score` (1–10) and `well7_fit` (1–10, primary sort key), runs a 20-item comparative editor pass, caps GitHub's shortlist share (`3`), discounts stale/unsubstantiated low-star repos, caches scores in `score_cache.json`, and walks a 4-model fallback chain on rate limits or empty responses.
- **Phase 3 (Fetch, grounded summaries & report formats):** `fetch_candidates.py` extracts full text via arXiv API, GitHub README, and `trafilatura`, falling back to snippet with explicit `(full text unavailable)` disclosure. `summarise.py` enforces source-only prompting, an `unsupported_numbers` fact guard, and extractive fallback. `report_build.py` verifies every link HTTP 200 (HN via Algolia; Google News redirects unwrapped or dropped), enforces per-section score floors (7 / 6 / 5) without padding, and writes `report.md`, `report.html`, a glossary-first PDF (`render_pdf.py`), and `run_log.json`.
- **Phase 4 (LangGraph agent):** `uv run python main.py --pipeline` executes the 7-node `StateGraph` (`collect → clean → rank → fetch → report → render → send`) over `AgentState`. Every node records errors rather than crashing, so a single source or model hiccup never halts the week.
- **Phase 5 (Email & GitHub Actions scheduler):** `emailer.py` sends one `multipart/alternative` HTML + plain-text email to the 5 `config.yaml` recipients, aligns `From` with `SMTP_USER` and `Message-ID` with the sender domain, retries only pre-DATA transient errors, and updates `history.db` solely after a real SMTP send (`--dry-run` writes `email.eml`). A real `send_report.py --test` reached Gmail's Primary Inbox. `.github/workflows/weekly-report.yml` is the sole live Saturday scheduler (`17 5 * * 6`, with `LLM_API_KEY`, `SMTP_*`, `MAIL_FROM`, and `CF_PUBLISH_TOKEN` configured; local Windows task `SyntheticDataWeekly` deleted), paired with `.github/workflows/cache-keepalive.yml` (Wednesday `05:17 UTC`) so GitHub's 7-day cache eviction never drops `history.db`.
- **Verification:** `selftest.py` passes **476/476** offline checks, `verify_report.py` passes **30/30** structural checks across all four archived week folders, and GitHub Actions dry-run [`44907469014`](https://github.com/badrbajamil1-collab/synthetic-data-weekly/actions/runs/44907469014) succeeded end-to-end (187 items, 5 picks / 1 tool / 1 worth-a-look, 7/7 live links, 0 errors).
