# Pipeline Improvements Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Apply all six groups of reviewer feedback to the Python pipeline while keeping the existing report contract and offline test suite green.

**Architecture:** A shared `week.py` fixes one Sunday–Saturday window for every stage. Six disjoint file-ownership slices are implemented by fresh subagents on `opencode/gemini-3.8-flash`; the controller owns `week.py`, `config.yaml`, `graph.py` and `selftest.py`, integrates, and verifies.

**Tech Stack:** Python 3.13 / uv, Windows PowerShell 5.1, pydantic `Item`, LangGraph `StateGraph`, httpx, feedparser, Jinja2, reportlab, sqlite3, PyYAML. Tests are `selftest.py` + `verify_report.py` (no pytest).

**Spec:** `docs/superpowers/specs/2026-11-11-pipeline-improvements-design.md`

## Global Constraints

- Run from repo root; `python` is NOT on PATH — use `.venv\Scripts\python.exe` or `uv run python`.
- No pytest/linter/CI. `selftest.py` and `verify_report.py` are the suite; both exit non-zero on failure.
- `selftest.py` assertions are written FIRST by the controller; implementers must satisfy them and **must not edit `selftest.py`**.
- `config.yaml` is owned by the controller. Implementers must not edit it; request new keys in their report instead.
- Do NOT touch `web/`, `src/synthetic_data/graph.py`, `config.yaml`, `selftest.py`, or `docs/`.
- Do NOT commit. The controller makes one commit at the end (parallel git index writes race).
- Hacker News returns HTTP 419 to non-browser clients — `links._check_hacker_news` verifies via Algolia; do not "fix" it into a plain status check.
- Google News RSS links are opaque redirects; `resolve_google_news` unwraps them via `batchexecute`. A 200 proves nothing.
- Reddit uses `.rss` with no trailing slash; keep the 15/30/45 s backoff.
- Markdown must still end with exactly `Auto-generated by the Synthetic Data Research Agent. Reply with feedback.` and start with `**Subject:** Synthetic Data Weekly — Week of `.
- `report_build.py` still exits 1 when it dropped dead links (successful filtered render).
- Rows in `ranked.json` are plain dicts, not `Item` (pydantic `extra="ignore"` would drop fields).
- `llm.py` owns transport retries; `rank.py` never retries a batch.
- Cache before duplicate grouping; a demoted duplicate score is never stored.
- No secret is ever written into `config.yaml`, `.env.example` or code.

## Interface Contracts (binding across tasks)

`src/synthetic_data/week.py` (controller, written before any dispatch):
```python
def week_bounds(run_date: date | None = None) -> tuple[date, date]
def in_week(value, bounds: tuple[date, date]) -> bool
```

`src/synthetic_data/models.py` (Task B): `Item.target_url: str = ""`.

`src/synthetic_data/links.py` (Task B):
```python
def canonical_target(url: str) -> str          # arxiv id / github owner/repo / doi, else ""
def story_key(item: dict) -> str               # prefers target_url, else canonical_target(url), else normalize_url(url)
```

`src/synthetic_data/llm.py` (Task B):
```python
def require_api_key(env: dict, names=("OPENROUTER_API_KEY", "LLM_API_KEY")) -> str
def chat(..., json_mode: bool = False) -> tuple[str, int]   # adds response_format, 400-fallback
```

`src/synthetic_data/rank.py` (Task B):
```python
RUBRIC_VERSION = "2026-11-11.1"
def prefilter_indices(items, keywords) -> set[int]
def rerank_top(rows, chat_fn, *, top_n: int = 20) -> list[dict]
def diversify_well7_fit(rows) -> list[dict]
def group_duplicates(items, threshold=0.80) -> list[dict]   # story_key first, then title Jaccard
```

`src/synthetic_data/collectors.py` (Task A): every `fetch_*(..., week: tuple[date,date] | None = None)`; `_in_window(published, cutoff, week=None)`.

`src/synthetic_data/summarise.py` (Task C):
```python
WORDS_LONG = 50
WORDS_SHORT = 20
def summarise_item(...) -> dict   # gains "why_it_matters": str
def summarise_trend(...) -> dict  # {"trend": "", "guard": "omitted"} on failure
def compose_sections(items, *, picks=6, max_tools=5, max_worth=5,
                     week_end=None, run_date=None,
                     min_score_top=7, min_score_tools=6, min_score_worth=5) -> dict
def dump_report(report, *, generated_at="") -> str  # emits why_it_matters; omits trend when empty
```

`write_report.py` (Task C): `pick_entry/tool_entry/worth_entry` carry `why_it_matters`; `SUMMARY_VERSION` bumped.

`src/synthetic_data/render.py` (Task D): `render_markdown(report)` / `render_html(report)` consume
`report.get("trend")` (may be missing/empty), `entry.get("why_it_matters")`, and
`report.get("source_counts")` (dict of collected-source name -> int).

`report_build.py` (Task E): injects `report["source_counts"]` before rendering and writes
`week_mode`, `week_start`, `week_end`, `trend_omitted`, `score_floors`, `source_counts`,
`dropped_below_floor` into `run_log.json`.

## Review Focus

1. **A replayed historical week** (`write_report.py --week-end YYYY-MM-DD`) must still produce the same week bounds — covered by Task C's `compose_sections` test with explicit `week_end`.
2. **An empty or missing trend** must not raise `KeyError` in any renderer — covered by Task D's render test with `trend=""` and by `verify_report.py`.
3. **A collector that returns nothing for the fixed week** must not crash the pipeline — covered by Task A's `_in_window` tests with a `week` argument.
4. **A partly failed run** must not lose `history.db` — covered by Task E's `filter_seen_urls` backup test.
5. **A provider that rejects `response_format`** must still return content — covered by Task B's `llm.chat(json_mode=True)` 400-fallback test.
